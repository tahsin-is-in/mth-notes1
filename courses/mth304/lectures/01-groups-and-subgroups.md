## 1.1 The group axioms

:::definition Group
A **group** is a set $G$ together with a binary operation $\ast$ such that:

1. **Closure**: $a \ast b \in G$ for all $a, b \in G$.
2. **Associativity**: $(a \ast b) \ast c = a \ast (b \ast c)$ for all $a, b, c \in G$.
3. **Identity**: there exists $e \in G$ with $e \ast a = a \ast e = a$ for all $a$.
4. **Inverses**: for each $a \in G$, there exists $a^{-1} \in G$ with $a \ast a^{-1} = a^{-1} \ast a = e$.

If additionally $a \ast b = b \ast a$ for all $a, b$, the group is **abelian**.
:::

Note that closure is often built into "$\ast$ is a binary operation on $G$" and stated separately only for emphasis when checking whether a subset forms a group.

## 1.2 First examples

:::example Familiar groups
* $(\mathbb{Z}, +)$ — the integers under addition, with identity $0$.
* $(\mathbb{Z}_n, +)$ — integers mod $n$, a finite abelian group of order $n$.
* $(\mathbb{R} \setminus \{0\}, \times)$ — non-zero reals under multiplication.
* $S_n$, the **symmetric group** on $n$ symbols, under composition — the first standard example of a **non-abelian** group once $n \geq 3$.
:::

## 1.3 Subgroups

:::definition Subgroup
A subset $H \subseteq G$ is a **subgroup** of $G$ (written $H \leq G$) if $H$ is itself a group under the operation of $G$.
:::

:::theorem Subgroup Test
A non-empty subset $H \subseteq G$ is a subgroup if and only if, for all $a, b \in H$,
$$
a \ast b^{-1} \in H.
$$
:::

This single condition replaces checking all four group axioms individually — closure and inverses come out of it automatically, and associativity and the identity are inherited from $G$.

:::example Applying the subgroup test
Let $H = \{0, 2, 4\} \subseteq \mathbb{Z}_6$. For any $a, b \in H$, $a - b \pmod 6 \in \{0, 2, 4\}$ (check the cases directly), so $H \leq \mathbb{Z}_6$. In fact $H$ is exactly the multiples of $2$ mod $6$ — a **cyclic subgroup** generated by $2$.
:::

:::important Exam tip
When asked to prove something is a subgroup, always reach for the subgroup test first — writing out all four group axioms from scratch is far more work than it needs to be, and examiners expect the shortcut.
:::
