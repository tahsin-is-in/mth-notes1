About MTH Notes

A personal Mathematics study library designed to keep lectures, notes, questions, formulas, and resources organized in one place.

Built for Mathematics students

MTH Notes started as a way to stop losing lecture notes across a dozen folders and chat threads. Every course, lecture, and question bank lives as plain text in a GitHub repository, and this site turns that repository into something that reads more like a digital textbook than a file listing \u2014 with search, bookmarks, and progress tracking that stay entirely on your device.

There is no login and no server: everything you mark as complete or favorite is stored in your browser's localStorage, which means it is private to you and free to run on GitHub Pages.
