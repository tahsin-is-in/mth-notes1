# PDFs go here

Drop any lecture slides, problem sheets, or scanned notes here as `.pdf` files,
then reference them from a course's `resources/resources.json`, e.g.

```json
{ "title": "Problem Sheet 2", "type": "pdf", "file": "../../../assets/pdf/mth301-problem-sheet-2.pdf", "description": "..." }
```

The sample `resources.json` files that ship with this project reference a few
PDFs that don't exist yet — replace them with your own, or delete the entries.
