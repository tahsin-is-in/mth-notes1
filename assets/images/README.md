# Images go here

Diagrams, plots, and photos used inside lecture notes. Reference them from a
Markdown file with a normal image link, using a path relative to the lecture
file, e.g. from `courses/mth301/lectures/03-uniform-convergence.md`:

```markdown
![Graph of f_n(x) = x^n](../../../assets/images/mth301-xn-graph.png)
```
